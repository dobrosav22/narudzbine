# Create-only CSV import refinement

Selected2026-10-20 under D-GOV-005 before dependent code; assistant choices, not new user answers. Implements previewCsvImport/getImportPreview/confirmCsvImport under R-CAT-058–065/071–075, D-PLAN-012 and approved transport/replay rules.

Use raw text/csv (optional charset=UTF-8, header=present only), max5,242,880 bytes, strict UTF-8 decoding, optional initial BOM, required exact case-sensitive distinct approved headers with sku/name mandatory, arbitrary header order. Quoting follows [RFC4180](https://datatracker.ietf.org/doc/html/rfc4180) section2; project-approved LF and CRLF are accepted and quoted CRLF normalizes to LF. Reject bare CR, NUL, malformed quoting/header, empty data and >1000 records as file-level422; mismatched row field count is a row error. A final newline adds no phantom record; other blank records count as invalid rows. Bound each decoded cell at20,000 UTF-16 units before field validation. Formula-looking text remains literal, never evaluated. No new parser dependency.

Parse outside business locks after current vendor catalogue authority/CSRF and committed admission; max3 preview attempts/vendor/rolling hour, including invalid files, plus ordinary API limits. Confirmation/replay does not consume another upload allowance. Reauthorize after parsing before storing. Reuse actual product request normalization/limits and price grammar; blank optional cells mean omitted/null/default, quantities default1, activation defaultfalse. Tags are a strict JSON UUID array, max50, distinct, canonical sorted; no reference creation. Allocate stable server UUIDv7 IDs to well-formed proposed rows; malformed rows are omitted from rows while rowCount/errors still include them. Aggregate all safely discoverable local/reference/reserved-SKU/duplicate/cap/activation errors, max100 per row, ordered row/column/code; duplicates mark every duplicate row. Existing normalized current/archived/retired SKU reservations all block creation. Previews hold no SKU/product slots and perform no catalogue/taxonomy/pricing/stock writes.

Preview persists normalized proposals/errors for30 minutes, immutable revision1 and original signed revision. Only own active vendor catalogue-authorized members may read/confirm; require current price capability for files containing any basePrice, including replay. All fixed vendor roles presently have these uniform capabilities. Activation requires unit+positive base price; tracking on always blocks new-row activation because CSV cannot initialize count. Inactive unpriced creation remains valid. Confirmation requires original preview expectedRevision, valid original preview, current time strictly before expiresAt, and all current references/reservations/capacity/activation/authority checks. New stale row errors return409 IMPORT_STALE with typed importErrors[], never partial writes. Initially invalid preview returns409 INVALID_STATE; correct/reupload it. GET after expiry returns409 PREVIEW_EXPIRED, including consumed previews; metadata does not grant authority. No preview edit API.

Preserve module graph. Vendor organization/account authority precedes inventory control and preview guard. No existing product/price row lock is acquired after preview guard; only new private product/price rows are created, not visible to concurrent transactions before commit. Existing vendor guard coordinates plan/taxonomy/SKU/mode changes. Bulk prevalidation uses bounded batched reference/SKU queries, not per-row SQL. Current products.create/basePricing.replace/products.publication retain their audited validation; no imported existing-product update.
